# nigelnayar.github.io

Personal portfolio site for **Nigel Nayar** — Electrical Engineering undergraduate at Universitas Indonesia, focused on analog IC design, embedded systems, and industrial automation.

🔗 **Live site:** [nigelnayar.github.io](https://nigelnayar.github.io)

## About

This repo hosts a static, no-framework portfolio built with plain HTML/CSS. It covers:

- **Home** — introduction, status, skills, and social links
- **About** — education, work experience (including PT Elsewedy Electric Indonesia), and role as Head of Electrical Division at Reignblaze TRUI (Tim Robotik Universitas Indonesia)
- **Projects** — write-ups of embedded systems, IoT, and analog IC design work
- **Extras** — a personal side page ("The Nigel Production") separate from the professional portfolio

## Tech Stack

- HTML5 + CSS3 (no build tools, no JS frameworks)
- Hosted via [GitHub Pages](https://pages.github.com/)
