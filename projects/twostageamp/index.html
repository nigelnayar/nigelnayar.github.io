CMOS Two-Stage Fully Differential Amplifier

Microelectronics Final Project

A stable CMOS differential amplifier using Xschem and IHPSG13G2 PDK technology to achieve high open-loop gain and CMRR.

I will detail the design, simulation, and analysis of Two-Stage Fully Differential CMOS Amplifier i made. The entire process is done in a open source EDA software called Xschem using the 130nm IHP PDK technology.

This project was developed as part of my Microelectronic Circuits coursework to fulfill a college assignment requirements.
