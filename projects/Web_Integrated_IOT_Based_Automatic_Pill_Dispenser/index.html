Web Integrated IOT Based Automatic Pill Dispenser (Mediciner)

Embedded Systems Practicum Final Project

A smart IoT-based automatic pill dispenser integrated with a web dashboard using ESP32 microcontrollers and Google Firebase cloud service.

Mediciner

Patient’s medicine negligence is a serious health problem that could reduce the effectiveness of treatment, especially for elderly patients. This project aims to design a device, called “Mediciner”, an automatic IOT-based medicine dispenser that is simple, open source, and affordable. This system is built using ESP32 microcontrollers that is integrated to Google’s Firebase’s Realtime Database to synch the schedule in real time. My system is equipped with LCD 20x4 I2C for hardware status visualization, time, and the next schedule, not forgetting web dashboard for remote monitoring and control.

This project was developed as part of my Embedded Systems coursework to fulfill a college assignment requirements.

Description

“Mediciner” is an IOT based medicine (or pill) reminder and dispensing device that is specifically designed to tackle patients’ medication non-adherence problems. In modern healthcare context, medication negligance–wether because of forgetfulness or unintentional double dosage–is a very serious problem, especially for elderly or chronically ill patients.

This device is quite similar to its state-of-the-art counterparts, like the simple electronic medicine box or other expensive commercial smart pill dispensers. Compared to them, “Mediciner” offers different approaches. Commercial pill dispensers commonly have a closed, propietary ecosystems. Most of them are quite expensive and fully dependent on each company’s servers. In contrast, “Mediciner” is designed as a low-cost devie with open source architecture that combines both offline reliability and the flexibility of online cloud control.

Architecture

The system is built upon a modular architecture:

  • Controller: ESP32 (handles Wi-Fi connectivity and logic).
  • Cloud Backend: Google Firebase (Realtime Database for scheduling and logging).
  • Actuation: Servo motors triggered by the microcontroller.

The core or “brain” of this device is ESP32 microcontroller that handles control logics and Wi-Fi communication. An SG90 micro servo is used as the actuator that moves the rotating disc mechanism to separate and dispense 1 or more pills at a time. For physical interface, we use a push button for manual override, in case of an emergency or for testing purposes.

For the servo setup we need to modify the width of the pulse. Since the SC90 Micro Servo operates in 50hz frequency, meaning the period of one cycle is 20ms. We use 16 bit for smooth servo movement. Thus, it has a resolution of 216 = 65536. Fot the lower constraint, we use a pulse width of 0.5 to prevent the servo to turn off or loose power. And because of that, since we need 2ms to reach 180 degrees, we will use 2.5ms as the upper constraint. Thus for the duty cycle we can calculate using (0.5ms/20ms * 65535 = 1638) and (2.5ms/20ms * 65535 = 8192).

I also implement LCD 16x2 with I2C communication as an additional feature to improve user interface experience. This screen shows vital information in real-time without having to connect to a computer. These information include: Wi-Fi Connection status, current time, servo angel, and “dispensing” message.

My device uses Firebase Realtime Database for backend. This enables user to set their own schedule for each dosage (alarm0 to alarm3) through web interface. The key feature that separates our device from the conventional method is the use of Non- Volatile Storage. This feature saves schedule and the current angle of the servo to ESP32’s Memmory. In addition, to simplify user’s interaction, I design a responsive web app using Firebase SDK. This web app acts as a control panel that allows the user to monitor in real time, manage schedules, and synch instantly.

In fact, you can even access my device's dashboard right now by clicking here. You can control the one and only device that is available through the dashboard from anywhere. Unfortunately I already scrapped the device for other purposes.

How It Works

The user inputs their medication schedule via a web interface connected to Firebase. The ESP32 constantly listens for changes in the database. When a scheduled time is reached, the ESP32 activates the servo motor to dispense the pill and updates the status to 'Dispensed' in the database.
