Smart Vertical Buffer System

Description

This is a simulation project for my Control Engineering Practiccum course. I use Factory.IO as a virtual environment to simulate the system. To program the automation system, i use ladder programming with EcoStruxure Machine Expert Basic by Schneider Electric.

This project is a simulation of smart elevator automation designed to efficiently distribute pallets from the input line to available storage levels. This mechanism operates by scanning the occupancy status at each level using retro-reflective sensors, then instructing the elevator to move pallets only to the detected empty shelf slots, thus preventing the accumulation of goods. This system uses a roller conveyor as a pallet base and integrates programming logic in the form of array data processing to track warehouse occupancy, and is equipped with an interactive operator panel for real-time system status monitoring.

Objects

The system uses these objects available on the simulator Factory.IO:

  • Conveyor Belt: To move the goods
  • Retro-Reflective Sensors: A photoelectric device that pairs an emitter and a receiver in a single housing. It emits a light beam that hits a reflector and bounces back to the receiver. When an object interrupts or breaks the light beam, the sensor triggers a switching signal.
  • Elevators: Heavy-duty chain-driven elevator, used for transportation of all sorts of cargo between floors. The elevator is equipped with two retroreflective sensors, placed at each end of the platform. The elevator can be controlled by digital or analog values, according to the selected configuration.
  • Boxes: These are used to simulate the goods.

How It Works

1. System Initiation & Entry Feed Control

Rung 0: System Master Control
Manages the primary operational state of the entire system utilizing latching logic. Pressing the physical Start button seals/latches the execution loop, while the Stop button breaks the circuit to reset the system state safely.
Start_Button Stop_Button System_Start (Latch)
Rung 1: Entry Feed & Emitter Interlocking
Controls the external entry conveyor line and the package emitter. The logic permits loading only when the core system is active, the elevator is physically resting at Floor 1, and the storage racking grid is verified to have open capacity.
System_Start Elevator_At_Floor_1 Rack_Full_Flag = False Entry_Conveyor_On Emitter_Active

2. Vacancy Scanning & Dynamic Routing

Rungs 2, 3 & 4: Conditional Slot Scanning & Target Assignment
Executes sequential vacancy inspections across warehouse levels using conditional Jump instructions. Retro-reflective sensors track storage availability, if an empty space is registered on an intermediate floor, the PLC instantly bypasses remaining checks and jumps directly to label L0 to assign that level as the destination.
Retro_Reflective_Sensors JMP L0 Target_Floor_Variable
Rung 5: Warehouse Capacity Exception (Full Condition)
Acts as a fallback catch statement if no conditional jumps were triggered (signaling all warehouse slots are full). It shifts the system into a standby routine, flashes a full warning indicator light on the control box, and cuts power to the entry emitter.
All_Slots_Occupied Full_Warning_Light Target_Floor = 1 Emitter_Halt

3. Lift Transit & Vertical Positioning

Rung 6: Elevator Entry Registration & Target Landing (L0)
The execution target point for the L0 jump commands. When a box fully clears the internal elevator entry/left sensor, it latches the upward travel flag. Simultaneously, it triggers a baseline clear operation to reset the warehouse full flag if space opens up.
Elevator_Left_Sensor Aktivator_Flag (Set) Reset_Full_Status
Rung 7: Upper Boundary Level Flag
Monitors specific uppermost thresholds, generating a dedicated positional status marker when the elevator platform reaches Floor 4.
Floor_4_Proximity Floor_4_Status_Flag
Rung 8: Elevator Lift Motor Actuation
Evaluates transit flags to govern vertical movement. While the Aktivator bit remains high, the primary lift motor is powered continuously to elevate the cargo cabin until it matches the targeted destination.
Aktivator_Flag Lift_Motor_Up
Rung 9: Motion Interlock & Standby State
Controls the structural execution hold state (Stun) of the elevator cabin, interlocking the lift during data updates until it safely steps down back at Floor 1.
Stun_Condition Transit_Interlock

4. Unloading, Braking & Return Sequences

Rung 10: Discharge Verification & Descent Timer Trigger
Monitors the photoelectric Exit Sensor placed on the outer edge of the elevator platform. When a box departs and clears the sensor, a off-delay timer flag (Downer) is launched, guaranteeing structural clearance before bringing the lift back down.
Exit_Sensor_Falling_Edge Downer_Descent_Timer
Rungs 11 & 12: Coordinated Material Transfer
Runs real-time comparative checks between the current vertical level and assigned target level variables. When a match is achieved, it powers the internal motorized conveyor of the elevator cab in tandem with that specific level's receiving rack conveyor.
Current_Floor == Target_Floor Cab_Conveyor_Forward Rack_Conveyor_Receive
Rungs 13 & 14: Inductive Level Deceleration (Braking Interlocks)
Handles precison leveling of the heavy metallic platform. By verifying inputs from non-contact inductive proximity sensors, the logic safely invokes the motor's Slow speed state *only* when arriving at the selected target level during ascent, preventing structural mechanical overshoot.
Inductive_Proximity_Sensor Ascent_Activeward Lift_Motor_Slow_Speed

Operational Summary Note:

The program architecture ensures safe vertical buffering by integrating optical retro-reflective sensors for cargo indexing and robust inductive proximity elements for structural alignment. Deceleration circuits prevent mechanical damage, and conditional logic loops effectively automate continuous package sorting with fallback safety checks.
